# Portafolio

Este repositorio es una muestra de diferentes proyectos en los que he trabajado en mi carrera, se encuentran distribuidos bajo licensia MIT y pueden ser usados, modificados y compartidos libremente haciendo referencia a mi como autor.


```
╭─ About me ─────────────────────────────────────────────────────────────────────────────╮
|                                                                                        |
│  Ingeniero de profesion, Analista por pasion y Programador por entretencion            |
|  Mi primer lenguaje fue BASIC en un Atari 800XL, donde mi primer logro fue hacer       |
|  un loop infinito.                                                                     |
|  Eventualmente modifique los archivos Gorillaz.BAS y Nibbles.BAS en QBASIC, para que   |
|  los colores del antiguo PC de mis padres un NCR System 3120 con pantalla              |
|  monocromatica se vieran mejor.                                                        |
|  Publique mi primer website en el año 97 en Geocities y Angelfire, creadas utilizando  |
|  Microsoft FrontPage y Macromedia Dreamweaver, donde colapse la internet de mi hogar   |
|  cuando monte un servidor FTP en el computador de la familia.                          |
|  En mi tiempo libre me gusta modificar la estetica de Linux y Windows, a traves de GTK |
|  Conky y Rainmeter, y hacer programas para llevarlo a cabo.                            |
|                                                                                        |
|  En la actualidad utilizo VBA, Python, SQL y HTML, para crear herramientas de          |
```
