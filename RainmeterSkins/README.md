Dos skins para Rain Meter

Estas skins son visualizadores de Feed HTML, emulando la experiencia RSS y filtrando
el ruido de que existen en las paginas web.

ANIME AV1

Es una skin especifica para el sitio de anime AniveAv1 donde muestra la informacion de los
ultimos 4 actualizacion del sitio. Muestra el nombre del show, hace cuanto tiempo fue
actualizado el show y el numero de episodio

TCB Scans

Es una skin especifica para el sitio TCB Scans, que dedica a traducir proyectos de Mangas
con una mejora substancial a las traducciones oficiales de VIS.
Busca los ultimos 4 proyectos actualizacion y nos muestra el nombre del comic, el numero
de capitulo, la fecha de lanzamiento y el titulo de capitulo.
